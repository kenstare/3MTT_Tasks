# Simple Linear Regression – Marketing ROI Analysis

## Project Overview
This project focuses on analyzing a historical marketing dataset to determine the return on investment (ROI) across various advertising channels: TV, Radio, and Social Media. Using Python and the `statsmodels` library, a Simple Linear Regression model was constructed to identify the specific advertising medium that yields the strongest linear correlation with sales revenue. 

Through exploratory data analysis (EDA), statistical modeling, and regression diagnostics, this project translates raw marketing metrics into a concrete, data-driven strategy for optimizing marketing budget allocation.

## Project Deliverables
* **Jupyter Notebook (`regression_analysis.ipynb`):** Contains complete, well-commented execution blocks covering data cleaning, visual exploration, model building, and diagnostics.
* **Diagnostic Visualizations:** Saved figures evaluating standard model performance assumptions (linearity, normality, and homoscedasticity).
